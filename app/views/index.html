Version 4.2

November 2026

Search and filters

  • Fixed search glitch where searching again on results wasn’t resetting the search
  • Operating status now shows “Open” and “Open, but proposed to close” as selected on filters by default.
  • Filter labels are now per-field: Operating status, Education provider type, Education group type, and “Section 41 (approved for SEND provision)”.
  • Added a Resourced provision filter.
  • A search with a single result goes straight to the record.

Search result cards

  • Provider cards show Local authority, Phase of education, Education provider type, DfE number, URN, Address and Part of group.
  • Group cards show Education group type and Address where the data has one. A lot of groups have no address recorded.

Provider pages

  • Renamed fields: Status → Operating status, Close date → Closed date, Pupil capacity → School capacity, “Name & role” → “Name and role”.
  • Pupils and capacity show as “6 (16 capacity)”, with the Summer census 2026 note right-aligned inside the existing rows.
  • Added Resourced provision and SEN unit numbers.
  • Added a Section 41 Yes/No row, hidden where it isn’t applicable.
  • Added “Date last changed/confirmed” as the last Details row.
  • Empty fields use per-field wording rather than “Not recorded”.
  • DfE numbers display in the 861 7007 format.
  • Added a green Open tag; Closed is blue.

Group pages

  • Added an ID numbers row, Education group type, Operating status with an incorporated or opening date, and Address.
  • Added a green Open tag.
  • School sponsor shows the sponsor name when one is recorded, and the row is hidden otherwise.
  • Group type labels use the format “Trust: Multi-academy”.

Downloads

  • Download buttons are now live CSV exports: “Download this record (CSV)” and “Download these results (CSV)”.
  • Added the new Selected records options and recalculated file sizes.

Content and navigation

  • FAQ, Glossary and Guidance now have breadcrumbs instead of Back links.
  • Fixed the FAQ page title.
  • Dates use the “1 Jul 2025” format. Date-range filters and static page copy keep full month names.
  • Four-figure numbers take a comma, per the GOV.UK style guide.
